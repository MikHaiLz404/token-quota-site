Support

Token Quota shows how much of your own AI subscription allowance remains — on your Mac, in a companion app and in widgets.

Need help? Email jojo.in.runtime@gmail.com. Including a redacted diagnostics export (see below) usually answers the first three questions at once.

Where the numbers come from

Every value Token Quota shows was reported by the provider itself. The app never estimates a quota, never invents a reset time or a period the provider did not report, and never shows an unavailable reading as zero — if something cannot be read, it says so instead.

A reading that has gone stale is marked stale rather than quietly presented as current.

Connecting and disconnecting a provider

Codex

Connect: Token Quota asks once for read access to your ~/.codex folder, so it can read the quota record Codex writes there. You pick the folder yourself; that is the whole setup.

Disconnect: revoke the folder access from Settings. Token Quota never asks for a Codex password or token — you sign in to Codex the normal way, in Codex.

If you have never run Codex on this Mac there is no record to read yet. That is not an error and not zero quota.

Claude Account

Connect: in Settings, enter the email of your claude.ai account and choose Add account. Token Quota opens Claude's own sign-in page in a browser window that belongs to Token Quota alone — separate from Safari, Chrome, and Claude Code. Claude emails you a verification code; you type it into Claude's page in that window. Never paste a cookie or password into Token Quota; there is nowhere to do so, by design.

Disconnect: Remove account. That deletes the stored session from the Keychain, clears Token Quota's own web data for Claude, and forgets the email.

If your account has no subscription allowance to track — an API-key-only session, for example — Token Quota shows No Subscription Quota. That is a healthy state, not an error.

Antigravity (AGY CLI)

Connect: choose Connect AGY…. Token Quota opens one folder picker at ~/.gemini/antigravity-cli, then shows you the exact current and proposed value of the single statusLine setting and asks for one confirmation. Nothing is written before you confirm. AGY CLI then writes a quota-only file that Token Quota reads.

Disconnect: Disconnect AGY… restores your previous status-line value and forgets the folder. If you changed the status line yourself after setup, your newer value is kept.

Quota appears after AGY CLI next updates its status line — until then Token Quota says it is waiting for provider activity.

OpenRouter API Usage

API Usage is metered spending, not subscription quota, and it appears on no widget. Open API Usage, read what it will do, accept it, and supply your own OpenRouter key; it is stored in the Keychain and used for one read-only request. Disconnecting deletes the key first, then the local reading.

Widgets

Add a Token Quota widget from the macOS widget gallery in small, medium, or large size. The large All Providers view is part of Pro. Widgets are read-only: they show the latest reading the app saved, and they never reach the network or display account identity.

If a placed widget stops updating, open Token Quota — the app is what refreshes it. Keeping widgets fresh in the background requires the app to stay resident, which it asks your permission for during setup.

Exporting redacted diagnostics

Open Diagnostics in the app and export. The export is created on your Mac and shared only if you send it. It deliberately excludes your account identity, credentials, file paths, and raw provider responses — it carries connection states, timestamps, and classified failures, which is what a bug report needs.
